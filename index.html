Personal e-ink dashboard

Your day, quietly on display.

JoanApp turns weather, calendar events and tasks into grayscale images for a Joan e-ink display.

How it works

The dashboard runs on a Raspberry Pi. It renders a rotation of screens and sends them to a connected display using Visionect Software Suite.

Optional Google connection

The owner can connect a Google account to show calendar events and incomplete tasks. Access is read-only: the dashboard does not create, change or delete Google events or tasks.

Personal installation

This website describes a personal dashboard. It does not provide public access to the dashboard or a Google sign-in service. This project is not affiliated with Google, Joan or Visionect.
