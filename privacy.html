Privacy policy

Updated 22 October 2026. This policy covers the owner's personal JoanApp installation.

Google data accessed

With the owner's permission, JoanApp reads calendar information and events using the Google Calendar read-only scope, and task lists and tasks using the Google Tasks read-only scope. It uses this information only to render calendar and task screens on the owner's dashboard and display.

Storage and display

OAuth authorization tokens are stored on the Raspberry Pi with restricted file permissions. Retrieved calendar and task information is cached for rendering. Rendered images containing that information are served by the Pi and sent to the local Visionect Software Suite and connected Joan display. People with access to the display or the installation's dashboard services may see the information shown there.

Sharing and use

JoanApp does not sell Google user data, use it for advertising, share it with data brokers, or use it to train AI models. Google data is used only for this personal dashboard and is not uploaded to this informational website. JoanApp's use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting and deletion

The owner can revoke access through Google Account connections. To remove local copies, stop the dashboard, delete its saved authorization token and rendered images, and remove any retained copies from Visionect Software Suite and backups. A displayed e-ink image can remain visible until replaced; push a blank image to clear it.

This website

These static pages contain no Google sign-in, analytics scripts or advertising trackers. The hosting provider may process ordinary web request information under its own privacy policy.

Contact and updates

For privacy questions, contact ppolkas@gmail.com. This policy will be updated if the installation's data practices change.
